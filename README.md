# MSPY2007-FOREVER

在 Windows 11 上安装使用 微软拼音输入法2007！

微软在 微软拼音输入法2007版 之后的版本中，砍掉了“微软拼音经典输入”模式，更是在 Windows 7 之后的系统中彻底删除了该输入法，用新的微软拼音输入法（与原来的版本没有任何关联）取而代之，导致“微软拼音经典输入”和“微软拼音新体验输入”两种模式完全消失。

又由于微软在 Windows 7 之后的系统（内置了新的微软拼音输入法）中，不允许安装旧版本，导致 微软拼音输入法2007版 再也无法安装使用。

这个问题困扰了我十几年。我甚至为了 微软拼音输入法2007版，多年坚持使用 Windows 7。

现在，我终于解决了 微软拼音输入法2007版 在 Windows 11 系统上的安装与使用问题。终于可以再次使用“微软拼音经典输入”模式了！

为此，我制作了安装包（到 Release 里下载），您可以在 Windows 11 系统中直接安装使用 微软拼音输入法 2007 版，并且它与系统自带的 微软拼音输入法 是各自独立的，互不影响。

另外，如果您只需要“微软拼音新体验输入”模式，而不需要“微软拼音经典输入”模式，可以去下载安装 MSPYForever
： https://github.com/Streamlet/MSPYForever
